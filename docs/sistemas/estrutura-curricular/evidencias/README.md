# Origem das evidências

Os arquivos deste nível foram recebidos com a baseline 1.9.3, incluindo execuções e reproduções históricas de versões anteriores. Suas contagens/versões não constituem novos testes da 1.10.0. O histórico em [HOMOLOGACAO.md](../HOMOLOGACAO.md) registra esse alcance.

A rodada atual tem pasta própria: [1.10.0](1.10.0/README.md), com oito logs completos, resultados, comparação de bytes/hashes, contraste e capturas sintéticas. Saídas reproduzíveis e dependências de teste permanecem fora do Git.
