# Exclusão de Disciplinas

Formulário em que o aluno pede a exclusão de matrícula em disciplinas do semestre. A planilha de respostas (chave `EXCLUSAO_DISCIPLINAS` no `ID_INDEX`) também é lida pelo Painel dos servidores e pelo gerenciador da equipe:

- [formulario/](formulario/README.md) — pedido enviado pelo aluno, com as disciplinas informadas pelo código;
- gerenciador da equipe — ainda não versionado neste repositório (fica parado até os formulários dos alunos serem reformulados).
