# Abertura de Habilitações

Pedidos de abertura de habilitação (Bacharelado e Licenciatura em Psicologia), enviados pelos alunos num Google Forms e tratados pela equipe do Serviço de Graduação. A planilha de respostas é a chave `ABERTURA_HABILITACOES` do `ID_INDEX`.

- [gerenciador/](gerenciador/README.md) — Web App da equipe para tratar os pedidos (**v2.0 no repositório, não homologada nem implantada**).
- O formulário dos alunos é um Google Forms e **não está no repositório**.

Documentação: [docs/sistemas/abertura-habilitacoes/](../../docs/sistemas/abertura-habilitacoes/README.md).
